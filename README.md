# YAN English Studio

适合中文母语初学者的独立雅思学习空间。雾蓝与奶白界面，手机和电脑可用，学习记录本地保存。**无需购买服务，无第三方项目依赖；AI 可选。**

[打开学习网页版](https://maquebaixue-ui.github.io/-yan-english-studio/) · [源码仓库](https://github.com/maquebaixue-ui/-yan-english-studio) · [MIT 许可证](LICENSE) · [内容来源与开源调研](SOURCES.md) · [隐私说明](PRIVACY.md) · [贡献指南](CONTRIBUTING.md)

## v1.13 See the World｜看见英语（第一阶段）

从「今日学习 → 看见英语」或「更多 → 看见英语」进入 #world。手机先打开后置摄像头、拍下这一刻，再核对照片并勾选本次识别许可；电脑或相机受限时可上传 JPEG / PNG / WebP。预览不上传，离开页面或切到后台关闭相机；离开页面清除内存照片。压缩画面最长边 1280px、JPEG 约 900KB 以内，重编码不保留相册 EXIF。

一次手动识别最多 5 个可见物品，标签位置由视觉模型估计，使用完整照片比例和细线定位，不承诺精确 AR 跟踪。点标签可看音标、中文、贴近画面的例句和口语表达，点击英式/美式使用设备英语语音。AI 生成内容明确标注、需要核对。收藏留下文字卡、场景和日期，出现收集印记；原始照片不会保存到词库、学习备份或 MCP。

收藏自动匹配原有词条，未收录的词使用稳定 world: ID。新增词进入词库搜索「身边的英语」及当天到期复习；收藏不增加每日20词完成量或伪造练习。实际复习后沿用不会/模糊/记住的原有日期规则，也支持原有拼写错题、四维训练与记忆巩固。学习备份保持 v1，新增 world.words / world.collection；旧备份初始化空探索记录。

### 安全视觉连接（必需）

本功能不使用浏览器里保存的聊天 Key。GitHub Pages 只提供静态界面和本地收藏，真正识别需要本机 Node 服务或已登录的私有 Sites 服务端。托管接口为同源 GET /api/vision/status、POST /api/vision/scan，不提供公共匿名识别代理。已有本机 .local/ai.json 的 Ollama/兼容 API 配置可复用；ChatGPT 文字授权不直接用于此视觉接口。

服务端可设置 VISION_PROVIDER、VISION_BASE_URL、VISION_MODEL、VISION_API_KEY。远程默认 compatible，仅允许 HTTPS OpenAI 兼容 Chat Completions 图像输入（user content 的 image_url 数据 URL）。托管 Sites 在运行环境变量中配置，VISION_API_KEY 必须标为 secret，再部署应用。密钥不会编入 JS、响应、日志或快照。主机没有这些变量时显示未配置，不生成演示识别。

DeepSeek 的 [官方视觉文档](https://api-docs.deepseek.com/guides/vision/)目前列出 base URL https://api.deepseek.com、模型 deepseek-flash。模型与账号须实际开放图像输入权限，不能假定旧的纯文本模型支持。其他兼容提供商填自己的官方地址和视觉模型。本机可复制 .env.example 为 .env，在本机编辑密钥后运行 node --env-file=.env server.mjs；.env 与 .local/ 均忽略，不上传。不要把真实密钥发在聊天或放进前端文件。

本机免费方案：Ollama 下载支持 vision 的本地模型，设置 VISION_PROVIDER=ollama 和实际模型名；沿用 [Ollama 图像接口](https://docs.ollama.com/capabilities/vision) 的 images 数组。免费指本地推理不购买 API，不表示手机能够独立运行该电脑模型。手机摄像头应通过 HTTPS 正式站点打开；同 Wi-Fi 的 HTTP IP 通常不能使用相机，可改为上传照片。

### 费用与数据范围

没有间隔自动扫描、自动重试或背景调用；第二阶段未启用。拍照与上传不调用模型，点扫描才发送一张。成功结果停留在当前帧，不重复请求；失败需要再次授权和手动重试。客户端及服务端间隔10秒，每用户每天最多30次请求尝试（UTC日）；托管计数保存在私有存储，本机计数在服务进程内。多实例竞争时限制为尽力保护，不能替代服务商硬额度；取消不能保证服务商未计费。视觉请求60秒超时。

MCP 原有工具不变，新增只读 get_shared_world_vocabulary。仍须在「AI 辅导与设置 → 连接我的 ChatGPT → 预览要分享的学习数据」确认分享，才可读取最近100张探索文字卡和复习日期；导入或收藏不触发分享，撤回副本仍有效。原图、摄像头与密钥不分享。照片只在本次请求转发至你配置的提供商，提供商留存规则取决于其政策。

### 安卓实际测试

1. 用安卓 Chrome / Edge 打开 HTTPS 正式站点的 #world，在聊天应用内先选“在浏览器打开”。
2. 点“打开摄像头”，允许相机，确认出现后置实时画面；拍杯子、书或植物。拒绝权限时应出现重试/上传说明。
3. 拍下后应停留在冻结画面、系统相机指示灯熄灭；在视觉连接显示已配置后，勾选这张照片的发送许可，点扫描。
4. 出现最多5个词，点标签检查卡片、英/美发音。位置为估计，可换角度重拍。空白、网络错误或不支持图像的模型必须显示失败提示，没有假识别。
5. 点“收进我的世界”，打开探索手册；刷新后收藏还在，原照片清除。在词汇页到期复习这个词，故意拼错应进入拼写错题本。
6. 导出学习备份，核对 world 文字卡存在、没有 image/base64/密钥。MCP 分享必须经过独立预览和确认。切页面或切到后台，相机应关闭。

本仓库的 QA 是真实浏览器手机尺寸与虚拟视频流验证，不等于实体安卓硬件验收；实际模型质量需在配置自己的视觉服务后测试。

## v1.11 更轻松的 AI 陪伴

进入「聊天陪伴」，可选择 **随便聊聊、英语小剧场、猜词小游戏、五分钟搭子**；聊天风格可选 **温柔接梗、轻松逗趣、安静陪着**。玩法和风格在当前页面生效，由已连接模型按固定提示执行，具体效果取决于模型。

「抽个话题」与开场按钮只在本地准备文字，点击发送才请求模型。已有草稿时先选择保留或替换；回复后可用「再给一点线索」「继续剧情」等按钮接话。默认不主动纠错，可开启温和纠错。小剧场是虚构情境，小游戏不计作正式学习成绩，五分钟搭子不运行后台计时或提醒。

连接方式与计费规则沿用现有配置：本地模型无需购买 API；手机直连已有 API 仍按服务商规则计费。最多发送最近 6 轮对话，聊天保存仍需自行开启。没有模型连接时不生成替代回复。

## v1.10 记忆巩固

在「更多 → 记忆巩固」或词汇页进入。每日新学词会自动开始跟踪；旧记录可点「开始跟踪已有词汇」，不补造历史成绩。

- **隔天盲测**：先看中文回忆英文，建议在打开普通词卡前测试；每轮最多 5 词。分别保存当天、隔天及以后、第 7 天及以后的独立匹配日期，两个延迟节点须在不同日期完成。它是轻量复习规则，不是经验证的记忆强度测量。
- **提示依赖**：首字母、实际播放的发音、完整答案，以及当天重做/看过普通卡片，均与答题时未点提示的结果分开。提示记录刷新后仍保留，当天重做不补算独立通过。
- **易混词对照**：6 组、12 句原创语境，先分别接触两词再开放。看对照后的练习、答题时再次看提示、当天看过反馈分别说明；错题接入原错题本。词形不匹配不自动认定近义表达错误，可自己选择加入拼写复习。

记录在当前浏览器本地，随学习备份导出/导入；保留最近 6 次明细及累计次数，不新增 AI 请求。首次缓存后可离线练习。

## 手机直接用：可添加到主屏幕的网页应用

**[点击打开 YAN English Studio 学习网页版](https://maquebaixue-ui.github.io/-yan-english-studio/)**

网站已部署，可直接使用。体验学习功能无需创建仓库、配置 GitHub Pages 或启动电脑服务；下方部署设置仅供想自行部署的人参考。

1. 用安卓 Chrome / Edge 打开网址；聊天软件内请先选择“在浏览器打开”。
2. 打开底部「更多」，等待显示“内置内容已准备好，可离线学习”。
3. 点“添加到主屏幕”，或浏览器菜单 →“安装应用 / 添加到主屏幕”。以后点桌面上的 YAN 图标进入。
4. 首次缓存完成后，词汇、间隔复习、语法、32 份原创材料、记录和备份可离线使用，电脑无需开机。外部官方 PDF、TED 和影视平台需要联网；4 份原创听力带内置合成音频，可暂停、调速和离线重播；私人音视频仍需手动选择文件。

iPhone 可用 Safari → 分享 → 添加到主屏幕。安装选项由浏览器提供；没有该选项也可以正常使用网页。旧版更新会先提示，不会在答题时自动刷新。浏览器可能回收缓存，出门前可在「更多」检查离线状态。

**手机 AI 可以直连已有 API，无需电脑保持开机。** 进入「更多 → AI 辅导与设置」，在顶部「手机 API 连接」填写 HTTPS 地址、模型名称和密钥，再保存。默认仅当前页面保留；也可勾选在自己的设备记住。勾选本次发送许可后发一句“你好”，收到真实回复才算验证成功。AI 需要联网，服务商可能按用量收费。接口必须支持浏览器跨域（CORS），不兼容时会明确报错，不使用公共代理。

**免费本地 AI 仍在电脑运行。** Ollama 通过下方电脑版本、同一 Wi-Fi 和配对码使用；添加到主屏幕不会把模型安装到手机。

**迁移旧进度：** 在旧网址「数据与设置」导出 JSON，传到手机，在新网址导入。网址、浏览器或设备不同，记录不会自动同步。安装应用也不是数据备份。

### 想自行部署：首次启用 GitHub Pages

打开仓库 **Settings → Pages → Build and deployment → Source → GitHub Actions**。本项目已有 `.github/workflows/pages.yml`，无需选择模板。首次 push 的工作流若因 Pages 未启用失败，设置后到 Actions → Publish mobile web app → Re-run failed jobs。

之后每次 main 更新都会测试、构建并部署，仅发布明确列出的公开静态资源。`.local`、私人资料、模型配置、QA 文件和 Node 服务不会上传到网页。GitHub Pages 为公开仓库提供免费静态托管；国内网络可达性取决于实际网络。

本地可用 `npm run build:pages` 生成 `.pages/`，该目录仅为构建输出。

## 电脑本机版快速开始

安装 Node.js 20 或更新版本，下载并解压项目，然后运行：

```sh
npm start
```

Windows 可以双击 **打开学习网页.cmd**。浏览器打开 **http://127.0.0.1:4173**。保留启动窗口，关闭后服务停止。不要直接双击 dist/index.html。

也可以克隆：

```sh
git clone https://github.com/maquebaixue-ui/-yan-english-studio.git yan-english-studio
cd yan-english-studio
npm start
```

安卓手机与电脑连接同一个 Wi-Fi，在手机浏览器打开启动窗口显示的 **Phone on the same Wi-Fi** 地址。电脑需要保持运行，IP 以启动窗口为准。项目不会自动修改防火墙；如打不开，请检查专用网络的 Node.js 入站权限和访客网络隔离。

手机底部「更多」可以进入资料库、AI 与数据设置。电脑左侧直接显示入口。[GitHub 仓库](https://github.com/maquebaixue-ui/-yan-english-studio)用于查看源码；直接学习请打开[学习网页版](https://maquebaixue-ui.github.io/-yan-english-studio/)。

## 每天怎么学

1. 今日面板先做到期复习，再学20个新词：看中文回忆英文、拼写、选择不会/模糊/记住。
2. 做5道语法题，重点留意时态、否定句与动词原形。
3. 在本地资料库做一篇听读短练习，或选一个写作/口语任务。
4. 检查听读题后保存真实正确题数；写作/口语记录具体反馈。实际练习会自动记录当天活动。
5. 重练错题；每周导出一次 JSON 备份。

## 本地内容与功能

- **6,000个独立词**：保留1,036张原创例句卡，新增4,964个MIT开源词典条目（中文与英语释义、可用音标及词形）。支持中英文搜索、按词库筛选、分页预览和单词自主练习；每日新词仍为20个，约300组。词典扩展暂无核验例句，页面明确标注，英语释义不冒充例句。词库不是官方IELTS词表，不按词数承诺分数。
- **80道语法题**：比初版新增30题；一次一题，解析和错题记录。
- **32份学习材料**：6篇阅读、4份听力文本、8份基础讲义、6个写作任务、8组口语话题。
- **50道听读题**：选择/判断、即时解析、错题收录，可保存真实正确题数；不是完整雅思模拟考。
- **间隔复习**：不会/模糊→明天；连续记住→1、3、7、14、30、60天。拼错时选择记住按模糊处理。这是简单规则，尚未使用 FSRS。
- **进度与错题本**：连续学习天数、当日任务、听读正确率趋势、写说反馈、五类错题重练。
- **数据备份**：导出、导入预览、结构校验、导入前备份与一次恢复，兼容初版 v1 备份和既有词/题 ID。
- **可选 AI**：连续陪伴对话、日常英语、学习鼓励和可选温和纠错；另有句子纠错、错题解释、中译英、写作与口语文字反馈。
- **官方与精选资料**：官方雅思样题、TED 演讲、生活情景剧及基础英语入口，可搜索和按分类筛选。目录保存在本地；视频不预装，联网条件逐项标明。详见 [资源目录](RESOURCE-CATALOG.md)。
- **我的影音**：选择自己的音视频及 SRT / VTT / TXT 字幕，点击时间跳转、A–B 循环、0.75 / 1 / 1.25 倍速，保存与导入导出听看笔记。

原创例句卡及练习为**AI辅助编写的学习示例，非雅思真题**。扩展词条来自MIT许可的ECDICT固定版本；完整许可证见 [ECDICT许可](third-party/ECDICT-LICENSE.txt)，来源版本和筛选规则见 [词库来源](dist/vocabulary-source.json)。听力朗读只使用设备已有的本地英语合成声音，明确标注非真人录音；没有本地声音时可阅读文本。没有冒充官方录音、官方评分或已连接的 ChatGPT 账户。

## 扩充离线资料

在项目目录运行：

```sh
npm run materials
```

脚本只从固定的官方链接下载免费 PDF，验证格式与大小后保存在 **.local/materials/**。打开「本地资料库 → 官方与精选」刷新本机文件，可筛选“只看本机可离线 PDF”。下载失败会逐项报告，可以再次运行；需要联网下载一次。

官方样题、评分标准和练习资料仍归原机构所有，个人副本不上传 GitHub，也不纳入源码 ZIP 或 MIT 授权。这里没有完整的商业剑桥真题书；Cambridge 官方备考入口可查合法教材和附带资源。TED 在官方播放器观看与切换字幕，美剧使用正版平台；账号、地区、订阅和版权限制以各平台为准。

「我的影音」只使用你主动选择、有权使用的文件。音视频通过浏览器临时文件地址播放，不上传、不写入学习备份；刷新网页后需重新选择文件。字幕支持最多 2 MB / 5000 句，笔记需单独导出 JSON。可用“先听一段 → 循环一句 → 看字幕 → 跟读两遍 → 记一句表达”的顺序学习。

## 我的 ChatGPT：两个入口

AI 辅导与设置顶部展开「连接我的 ChatGPT · 登录与 MCP」。

**在 ChatGPT 里使用学习工具：** 打开该面板中的私有学习连接，在私有站点登录。旧记录先从公开网页导出，在私有站点导入。点「预览要分享的学习数据」，核对完整内容并勾选确认。安装站点的私人 MCP 插件后，可以查询词库、原创材料、已分享的进度与错题。五个工具均只读，不自动同步，不包含密钥、聊天或私人影音。可撤回分享副本。

**在项目网页内使用 ChatGPT 额度：** 目前仅电脑本机版支持官方开源授权。用启动脚本打开 127.0.0.1 页面 → AI 辅导与设置 → 连接我的 ChatGPT → Continue with ChatGPT → 在官方页面自行授权 → 回到项目读取账号模型 → 选择模型。每次发送仍需勾选许可。不需要 OpenAI API key；是否可用由账号实际权限/额度决定。不会导入你原来的 ChatGPT 聊天和记忆。

**手机限制：** 官方开源登录要求本机回调；GitHub Pages 独立手机网页不能完成该回调。托管网页登录/额度使用需官方接入资格，当前未开通。私有站点的身份登录不代表可使用 ChatGPT 生成；手机可以使用 MCP，网页内聊天继续用已有 API。电脑本机授权后也可通过同一电脑配对使用，电脑需运行。

实现和边界见 [ChatGPT 与 MCP 接入说明](CHATGPT-MCP.md)、[隐私说明](PRIVACY.md)。官方说明：[开源登录](https://developers.openai.com/siwc/token-sharing-open-source/sign-in)、[模型与生成](https://developers.openai.com/siwc/token-sharing-open-source/models-and-inference)、[网站登录试点](https://developers.openai.com/siwc/website)、[MCP 连接](https://developers.openai.com/plugins/deploy/connect-chatgpt)。

## 手机直连已有 API

1. 手机打开学习网页 → 更多 → AI 辅导与设置 → 顶部「手机 API 连接」。
2. 填写服务商的 HTTPS Base URL、可用模型名称和 API 密钥；兼容 POST /chat/completions。填写完整接口地址会自动移除末尾 /chat/completions。
3. 保存设置（仅保存，不消耗 API）。默认只放在当前页面内存；显式勾选记住后才未加密保存到此浏览器的独立设置中。不要在共享设备保存密钥。
4. 在陪伴或辅导中输入文字，核对目标地址，勾选本次发送许可并发送。可以取消；失败保留草稿，不伪造回复。
5. 「移除 API 连接」同时删除当前页面和此浏览器保存的密钥，不删除学习记录。API 设置不进入学习/聊天备份，不自动同步。

服务商必须支持浏览器 CORS，允许来源 `https://maquebaixue-ui.github.io`、POST 方法和 Authorization / Content-Type 请求头。网页不能解除服务商限制；不支持时需由服务商开放跨域或使用你自己管理的 HTTPS 服务。不使用第三方公共代理。无用户 API 密钥，无法替用户验证真实模型效果。没有项目代付额度或内置免费云端 AI。

## AI 陪伴怎么用

完成下方模型配置后，在「聊天陪伴」说一句自己的话。可以聊日常、表达疲惫、练习简单英语，也可以请它把任务拆成五分钟。聊天不会自动计入学习完成量。

- 默认仅在当前页面内存保留；在“聊天保存与备份”显式开启本浏览器保存，才能刷新后继续。
- 每次发送最多附带最近 6 轮、12000 字符的聊天上下文；不会自动读取学习记录、题库、私人音视频或其他应用。
- 可选择聊天时温和纠正一处英语错误；可取消生成，导出、预览导入或清空聊天。
- 本浏览器最多保留 100 轮或 160000 字符；超限移除最早完整问答。聊天有单独的 JSON 备份，不包含在学习进度备份中。
- 它是 AI，回复可能有误。没有连接模型时只提示连接问题，不提供预制回复冒充 AI。没有跨应用记忆或后台提醒。

## 免费本地 AI：Ollama

基础学习无需 AI。需要 AI 时：

1. 从 [Ollama 官网](https://ollama.com/download/windows)安装并启动运行时。
2. 在终端下载一个本地聊天模型，例如：

   ```sh
   ollama pull qwen3:4b
   ```

   [示例模型约2.5GB](https://ollama.com/library/qwen3:4b)，下载需要网络和磁盘空间，运行速度取决于设备。项目不会自动下载模型，可改用已安装的其他本地聊天模型。
3. 在电脑 **127.0.0.1:4173 → AI 辅导与设置** 点「检查连接」，填写实际模型名称，保存。
4. 在「聊天陪伴」发送一句话，或进入「AI 辅导与设置」填写英文。只有收到模型真实响应才会展示 AI 回答。

本地模式只调用本机 Ollama，过滤云端模型，不需购买 API。模型可能解释错误，请与已有解析核对。AI 不给官方 IELTS 分数；口语文字稿不支持发音评分。

手机使用 AI：电脑 AI 页检查连接后展开「查看本次手机配对码」，在手机 AI 页输入。配对码只存在本次页面内存，重启服务后失效；手机不能修改接口设置。

### 预留已有 API

在电脑 AI 页选择「已有 OpenAI 兼容 API」，填写 HTTPS Base URL（通常以 /v1 结尾）、模型名称和密钥。适配 POST /chat/completions，不是所有厂商或模型都兼容。

- 密钥仅写入 .local/ai.json，不进入前端存储、学习备份或 Git 提交。文件未加密，勿分享。
- 换到不同接口地址必须重新填写密钥，防止误发旧密钥。
- 远程请求需每次勾选允许发送。练习辅导发送当前文本；陪伴发送当前发言及最近对话，页面会明确提示。不会上传整个学习历史。
- 已有 API 可能计费；项目不会购买额度或默认调用付费 API。
- 切回本地模式并保存会移除配置文件中的 API 密钥。

GitHub Pages 纯静态托管支持手机直连兼容 API；免费本地 Ollama 仍通过本机 server.mjs 运行。不要将带密钥的个人本机服务开放到公网。

## 数据保管

数据属于**当前设备 + 浏览器 + 网站地址**。127.0.0.1、localhost、局域网IP、手机和电脑彼此不自动同步。

更换设备或地址前，在「数据与设置」导出 JSON，传到新设备后导入。导入替换现有数据，先核对摘要；可恢复上一次导入前记录。存储不可用或旧数据损坏时会显示提示并保留旧数据供下载。

辅导问答默认只在当前页面内存，可主动下载或将写作/口语反馈保存为练习记录。陪伴对话可选择本浏览器保存，需单独导出；影音笔记也需单独导出。整个项目不连接其他 APP、小屋或记忆系统。

## 单词发音与内置听力（1.6.1）

词汇卡正面、释义和结果页有“听发音”，原创例句卡展开后还可“听例句”。支持正常/慢速、英式/美式偏好和停止；实际声音由手机/浏览器提供，部分声音需要联网。没有英语声音时可查看卡片的“没有声音？”说明，不需要 AI 接口。拼写作答阶段不显示英文或发音按钮。

“资料 → 原创练习 → 听力”有 4 份可直接播放的音频，也可在资料首页点“直接听一段”，或进度页点“先做一份听力”。这些是本项目原创文本的合成英语朗读，不是雅思真题、真人录音或官方听力材料。音频随公开文件缓存，支持离线播放和拖动进度；官方与 TED 的外站内容仍需按源站方式在线访问。

生成工具：Windows 安装 Microsoft Zira Desktop 后，从项目根目录运行 `powershell -File scripts/generate-listening.ps1`，仅对项目原创听力文本生成 16 kHz 单声道 8-bit PCM WAV。浏览器直接播放已提交的音频，不需要 Windows 或安装该声音；未分发语音引擎或语音模型。

## 专项训练与四维记录（1.7.0）

在“今日学习”点“打开今日专项”，或手机“更多 → 今日专项”。每天建议 5 个听写与辨义、3 句句型变换、1 个例句填空；按现有错词、到期复习、语法错误选择重点。首次开始时固定当天清单，刷新、重练或其他窗口保存不会重排；新一天再根据记录生成。不改变原有每日 20 个新词，也不把专项当成完成原有每日任务。

单词分别记录认识、听懂、拼对、会用的实际尝试与最近结果；老背词记录不补算听力或应用能力。听写把辨义和拼写分别计分，句型练习共有 24 道原创题，支持所列缩写和标点变化；例句填空仅核对卡片目标词，不是开放表达评分。错误自动进入原有类别错题本，可重练。专项开始、记录及四维数据保存在同一份本地备份；旧版 v1 备份可导入并初始化空专项记录。

本地能力结果是练习记录，不是能力等级或雅思分数；声音仍使用设备语音，只有点击才朗读。声音候选未确认前不会替换现有音频。

## 免费自然男声（1.8.0）

「更多」可选择男声②（M2，默认）、④（M4）、⑤（M5），偏好仅保存在当前设备。三段试听、起步20词和4篇原创听力均提供预制MP3，缓存后可离线播放，不调用语音API。词卡和专项听写也可切换声音。

完整6000词及原创例句的自然男声需要主动下载约400MB可选语音包（建议Wi-Fi），使用固定版本Supertonic 3与ONNX Runtime Web在浏览器Worker内合成，文字不发送给资源站。首次资源来自Hugging Face和unpkg；资源缓存独立于学习记录。未启用时其余词条使用设备英语语音并明确标注。实际速度、内存和声音播放限制由手机与浏览器决定；首次生成后若系统要求再次点击，重播会使用已生成声音。语音包被浏览器清理后需重新准备，移除语音包不删除学习记录。自然男声口音固定，“设备口音”设置仅影响设备语音。

模型为OpenRAIL-M许可，详见dist/audio/voices/model-license.txt及source.json；项目代码MIT许可不替代模型许可。仓库不包含约400MB模型权重，不使用付费API或未经确认的声音克隆。

## 每日方法路线（1.9.0）

从首页“今日方法路线”、更多“学习方法”，或专项训练顶部进入。建议约25分钟：复习5分钟、听写5分钟、逐句精听10分钟、中译英5分钟，可以拆开完成，不改变原有每日任务。

四篇原创听力共30句，②④⑤三种男声均有生成时长核对过的切句时间。先听整段写大意，再逐句对照文本，最后隐藏文本跟读；可以循环一句、标记没听懂、手动确认跟读。仅使用已内置的合成音频，无需下载大模型，不录制或评价发音。

12组原创短句按“看例句→补缺词→中译英”逐步减少提示，覆盖否定句、过去时与疑问句。符合指定参考句型会核对通过；其他译法不自动判错，只有学习者确认写错后才进入错题本。自行核对的完成记录与参考匹配次数分开。

错题可选择不认识词、听不出、拼写、时态、否定、信息定位或暂不确定，主动安排次日再练。到期项目优先出现在方法路线；同类新句子的练习不会消除原错题。精听、输出阶段、错因与复习日期包含在原有v1学习备份中，旧备份会补空结构，不虚构完成数据。
